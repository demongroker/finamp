# Jellyamp privacy

Jellyamp is a **local/self-hosted** client for *your* Jellyfin server.

- It does **not** require an account with demongroker, Finamp, or any third-party music store.
- Library metadata, streams, and downloads go to the Jellyfin server **you** configure.
- Optional features (Discord RPC, remote “Play On”, server sharing on LAN) only run when you enable them.
- Crash logs you choose to export stay on your device until you share them.

This fork does not add analytics, ads, or cloud accounts.

For upstream Finamp privacy context, see the [Finamp project](https://github.com/finamp-app/finamp).
