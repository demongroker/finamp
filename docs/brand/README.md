## Voice

- **Jellyamp** — product name (always capital J).  
- “Based on Finamp” — credit upstream when describing origin.  
- “For your Jellyfin library” — positioning; never imply cloud streaming of third-party catalogs.

## Don’t

- Don’t use official Finamp store listing assets as if this were the upstream app.  
- Don’t claim Play Store / App Store listing unless you publish under your own listing.
