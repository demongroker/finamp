## Review 1: "Library browsing needs much more power"

Biggest missing area. Albums/Tracks alphabet scrollbar = keep (excellent for large collections).

Wants a filter/sort button that opens:

**Sort options:**
- Title, Artist, Album Artist, Date Added, Release Date, Year, Play Count, Last Played, Rating, Duration, Random

**Filter options:**
- Downloaded, Favorite, Unplayed, Recently Added
- Genre, Year, Artist, Album Artist, Codec, Bitrate

**Behavior:**
- Ascending / Descending toggle
- **Remember the choice per view** (persisted per screen):
  - Albums page → always Date Added ↓
  - Artists → Name ↑
  - Tracks → Recently Played ↓

Power-user feature, would use constantly.
